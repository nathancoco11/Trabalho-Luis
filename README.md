📋 Sistema de Gestão de Ocorrências e Atividades
Sistema web para gerenciamento de ocorrências, agenda, mapeamento e presença, desenvolvido com HTML, CSS e JavaScript (ou tecnologias afins). Ideal para controle de eventos, monitoramento de atividades e registro de frequência.

📂 Estrutura de Páginas
O sistema é composto pelas seguintes páginas:

Página	Arquivo	Descrição
Inicial	index.html	Página principal com resumo, painel de controle ou dashboard.
Ocorrências	ocorrencias.html	Registro e listagem de ocorrências (incidentes, alertas, observações).
Agenda	agenda.html	Visualização e gerenciamento de compromissos, eventos ou tarefas.
Mapeamento	mapeamento.html	Mapa interativo para localização de pontos, rotas ou áreas de interesse.
Presença	presenca.html	Controle de frequência de usuários, alunos ou participantes.
🚀 Funcionalidades Principais
✅ Interface responsiva e intuitiva

✅ Navegação entre páginas via menu lateral ou superior

✅ Registro e consulta de ocorrências

✅ Visualização de agenda (diária, semanal ou mensal)

✅ Mapa com marcadores e geolocalização

✅ Controle de presença com listagem e status (presente/ausente)

🛠️ Tecnologias Utilizadas
HTML5

CSS3 (com Flexbox/Grid)

JavaScript (Vanilla ou com bibliotecas)
